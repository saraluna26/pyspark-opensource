# PySpark Project with New York City Airbnb Open Data

This repository contains practical exercises to learn PySpark from scratch, using the public dataset **New York City Airbnb Open Data**. The exercises are organized from basic to advanced difficulty to facilitate progressive learning.

## Contents

- Dataset: [New York City Airbnb Open Data](http://insideairbnb.com/get-the-data.html)
- Python code using PySpark.
- PySpark environment setup on macOS.

## Requirements

- Python 3.8+  
- Java JDK 17  
- PySpark
